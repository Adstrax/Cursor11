# Cursor11 V1.0

Cursor11 is a Windows 11 rounded cursor set with English and Simplified Chinese
installers. This release contains the light theme only.

## Highlights

- 17 cursor roles, including help, working, busy, precision, text, handwriting,
  resize, move, alternate, link, person, and pin cursors.
- Enlarged narrow isosceles rounded triangles for directional cursors.
- Beam B with standard 15 px top and bottom caps.
- Rounded precision crosshair and continuously filled move cursor.
- White glyphs with black outlines and shadows for the light theme.
- One visible installer in each extracted package, with internal files kept in
  `_internal`.
- Install Cursor11 and Restore Windows Default actions in the installer.

## Installation

1. Download the ZIP for your language.
2. Extract the entire ZIP.
3. Open the extracted folder and run `Install Cursor11.cmd` or
   `安装 Cursor11.cmd`.
4. Choose Install Cursor11 or Restore Defaults.

If an open application continues to show an old cursor, reopen it. If system
cursors do not update, sign out of Windows and sign back in.
