# Cursor11

Windows 11 概念光标套装的 Cursor11 亮色设计版本。

## V3.0.0 设计

- 17 种 Windows 亮色光标角色。
- `horz`、`vert`、`dgn1`、`dgn2` 使用瘦长等腰圆角三角形。
- 方向图标进一步放大，双三角形间隔保持约 8px（96px 设计基准）。
- `move` 中心连续填充。
- `beam` 使用 B 方案标准端帽，顶部和底部宽度为 15px，主体对称缩短约 6%。
- `precision` 使用圆角十字精准指针。
- 其余光标保持现有轮廓，并应用亮色层次。

## 发布包

- 英文版：`Cursor11-V3.0.0-en-US-Windows.zip`
- 简体中文版：`Cursor11-V3.0.0-zh-CN-Windows.zip`

两版共用同一套光标。英文包根目录为 `Install Cursor11.exe`，简体中文包根目录为
`安装 Cursor11.exe`；脚本和光标资源均放在 `_internal`。

## 安装

解压对应语言的 ZIP，然后双击根目录中的唯一安装入口。安装窗口提供安装
Cursor11 和恢复 Windows 默认光标两个操作。
