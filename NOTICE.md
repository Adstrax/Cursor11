# Attribution and Distribution Notice

Cursor11 is based on the Windows 11 Concept cursor set.

Original concept design: **Jepri Creations**  
https://www.deviantart.com/jepricreations

The Cursor11 artwork includes modified directional cursors, a beam cursor with
standard end caps and a 6% shorter stem, and a rounded precision cursor. The
remaining light-theme cursor silhouettes retain the original concept artwork.

Redistribution authorization for this release was confirmed by the repository
owner before publication. Retain this attribution when redistributing the
release packages.
